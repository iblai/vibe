# AGENTS.md

This is **iblai/vibe** — the developer toolkit for building AI-powered
apps on the [ibl.ai](https://ibl.ai) platform: Claude Code skills,
project templates (vibe-starter), and `@iblai/iblai-js` SDK wiring.

- **Full agent guidance lives in [CLAUDE.md](CLAUDE.md)** — read it first.
- **Skills live in `skills/<name>/SKILL.md`.** Start with
  [`skills/iblai-vibe/SKILL.md`](skills/iblai-vibe/SKILL.md) — the
  ecosystem index mapping this repo and its companions
  ([`iblai/api`](https://github.com/iblai/api),
  [`iblai/os`](https://github.com/iblai/os),
  [`iblai/vibe-marketing`](https://github.com/iblai/vibe-marketing))
  to tasks.
- Install the skills into your agent: `npx skills add iblai/vibe --all`.
  Cursor and Codex rule formats are pre-generated in `adapters/`.
