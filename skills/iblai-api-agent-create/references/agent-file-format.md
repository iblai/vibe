# .iblai Agent File Format

> **Preserved developer doc**, complementing **`/iblai-api-agent-create`**. No REST endpoints here —
> the `.iblai` format is a portable agent definition kept in a separate repo; once you have one,
> create the agent on the platform via the skill's **Writes**.

[`iblai/standard`](https://github.com/iblai/standard) defines `.iblai`: a Markdown-based,
human-readable format for portable agent definitions, so one agent description can be shared and
deployed across different platforms. The format is open source; clone
[`iblai/standard`](https://github.com/iblai/standard) and read its specification to define your own
portable agent configurations.
