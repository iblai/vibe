## Overview

**iblai-mcp** provides a collection of Model Context Protocol (MCP) servers designed for the ibl.ai platform. These servers expose platform capabilities as tools that AI agents can use, enabling deep integration between language models and ibl.ai services.

```bash
git clone https://github.com/iblai/iblai-mcp.git

```

Follow the setup instructions to configure and run MCP servers for your ibl.ai deployment.
